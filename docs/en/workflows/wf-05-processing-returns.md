# How-To Guide 5: Processing Customer & Supplier Returns

**Who is this for?** Cashiers, Return-Counter Staff, and Inventory Managers.  
**Full Module Reference:** [Sale Returns](../modules/sale-returns.md) | [Purchase Returns](../modules/purchase-returns.md)

---

## Step-by-Step Instructions

### A. Customer Sale Return (`/sale-returns/create`)
1. Go to **Returns → Sale Returns → Create**.
2. Select **Customer** and pick the original **Sale Invoice** (recommended—prevents over-returning).
3. Enter **Return Qty** (`<= Returnable`).
4. Choose **Instant Refund (Cash/Bank)** for walk-in refunds or **Adjust Customer Ledger (Credit Note)** for credit customers, then click **Create Return**.

### B. Supplier Purchase Return (`/purchase-returns/create`)
1. Go to **Returns → Purchase Returns → Create**.
2. Select **Supplier** (and optional **Purchase Invoice**).
3. Pick the medicine and **Batch #**, enter **Return Pack/Unit Qty**, select **Adjust Supplier Ledger (Credit Note)**, and click **Save**.
