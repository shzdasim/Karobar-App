# Training Lesson 7: System Administrators

**Objectives:** Manage Users, Roles, Operator PINs, Printers, WhatsApp/Email sharing, Automated Backups, License activation, and Multi-PC LAN Terminals.

## Instructions & Examples
1. **Access Control:** Create least-privilege **Roles** (`/roles`) and individual **Users** (`/users`), set 4-digit **Operator PINs**, and deactivate departed staff.
2. **Hardware & Sharing:** Configure 80mm/58mm thermal printer in **Settings → Print & Receipt Layouts** and run **Test Print**; pair WhatsApp QR in **Document Sharing**.
3. **Safety & LAN:** Enable **Automated Schedule** in **Backups & Storage** (`/backups`), download an off-PC backup weekly, and monitor counter PCs on `/server-dashboard`.

## Practice Exercises
1. Create a *Counter Cashier* role without delete/profit permissions and assign it to a test user.
2. Run a manual backup in `/backups` and verify **Automated Schedule** is enabled.
