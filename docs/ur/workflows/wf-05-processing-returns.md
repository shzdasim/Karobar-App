# رہنمائی 5: کسٹمر اور سپلائر ریٹرنز پروسیس کرنا

**کس کے لیے ہے؟** کیشیئرز، ریٹرن کاؤنٹر اسٹاف اور انوینٹری مینیجرز۔  
**مکمل تفصیل:** [سیل ریٹرنز](../modules/sale-returns.md) | [پرچیز ریٹرنز](../modules/purchase-returns.md)

---

## مرحلہ وار طریقہ کار

### الف۔ کسٹمر سیل ریٹرن (`/sale-returns/create`)
1. **Returns → Sale Returns → Create** کھولیں۔
2. **Customer** اور اصل **Sale Invoice** منتخب کریں۔
3. **Return Qty** درج کریں (`Returnable` حد کے اندر)۔
4. نقد واپسی کے لیے **Instant Refund (Cash)** یا اُدھار کھاتے کے لیے **Credit Note** چن کر **Create Return** دبائیں۔

### ب۔ سپلائر پرچیز ریٹرن (`/purchase-returns/create`)
1. **Returns → Purchase Returns → Create** کھولیں۔
2. **Supplier** (اور اختیاری **Purchase Invoice**) منتخب کریں۔
3. دوائی اور **Batch #** چنیں، واپسی کی مقدار درج کریں، **Credit Note** منتخب کر کے **Save** کریں۔
