# رہنمائی 3: بارکوڈ POS اور کاؤنٹر پر دوائیاں فروخت کرنا

**کس کے لیے ہے؟** کاؤنٹر کیشیئرز اور سیلز مین۔  
**مکمل تفصیل:** [بارکوڈ POS](../modules/barcode-pos.md) | [سیل انوائسز](../modules/sale-invoices.md)

---

## مرحلہ وار طریقہ کار

1. یقینی بنائیں کہ **Cash Drawer** شفٹ کھلی ہے (`/cash-drawer`)۔
2. **Invoices → Barcode POS** (`/sale-invoices/pos`) کھولیں۔
3. دوائی کا بارکوڈ اسکین کریں (`F2`) یا `F3` دبا کر نام یا سالٹ سے تلاش کریں۔
4. خودکار منتخب شدہ **FEFO بیچ** چیک کریں اور **Pack / Unit** مقدار سیٹ کریں۔
5. اگر گاہک انتظار کروائے تو `F8` دبا کر بل **Hold** کریں اور اگلے گاہک کو ڈیل کریں۔
6. **Cash**، **Card**، **Mobile Wallet**، یا **Split / Credit** منتخب کریں، **وصول شدہ رقم** لکھیں اور بقایا (Change) چیک کریں۔
7. بل محفوظ اور تھرمل پرنٹ کرنے کے لیے `F9` دبائیں۔
