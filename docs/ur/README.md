# کاروبار ایپ صارف دستاویزات (اردو)

**کاروبار ایپ (Karobar-App)** کے مکمل یوزر مینوئل میں خوش آمدید۔ یہاں ہر چیز آسان اور عملی اردو میں لکھی گئی ہے تاکہ آپ اپنی فارمیسی یا میڈیکل اسٹور کا روزمرہ کام آسانی سے چلا سکیں۔

---

## 1. فوری آغاز اور رہنما گائیڈز
- [آغاز گائیڈ (Getting Started)](../customer/ur/GETTING_STARTED.md) — پہلا لاگ اِن، سیٹ اپ وزرڈ اور پہلے 5 اقدامات۔
- [فارمیسی مالک اور مینیجر گائیڈ](../customer/ur/OWNER_GUIDE.md) — اسٹاف کنٹرول، ایکسپائری سے بچاؤ اور منافع کی حفاظت۔
- [تمام فیچرز کا تعارف](../customer/ur/FEATURE_GUIDES.md) — ہر اسکرین اور آپشن کا مختصر نقشہ۔
- [لغت اور اصطلاحات (Glossary)](../customer/ur/GLOSSARY.md) — آسان اردو وضاحتیں (FEFO، MRP، پیک سائز، کھاتہ، قرنطینہ)۔
