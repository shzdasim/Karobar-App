# تربیتی سبق 2: کاؤنٹر کیشیئرز

**مقاصد:** کیش ڈراور شفٹ کھولنا/بند کرنا، بارکوڈ POS پر تیز بلنگ کرنا، بل ہولڈ کرنا، اسپلٹ پیمنٹ لینا، اور سیل ریٹرن بنانا۔

## ہدایات اور مثالیں
1. **شفٹ شروع کرنا:** **Cash Drawer** (`/cash-drawer`) ← `Rs. 5,000` کے ساتھ **Open Shift** کریں۔
2. **بارکوڈ POS (`/sale-invoices/pos`):** اسکین کے لیے `F2` یا سرچ کے لیے `F3` دبائیں؛ **Pack/Unit** منتخب کریں؛ بل ہولڈ کرنے کے لیے `F8` اور مکمل کرنے کے لیے `F9` دبائیں۔
3. **سیل ریٹرن:** **Sale Returns → Create** (`/sale-returns/create`) میں اصل بل منتخب کر کے **Instant Refund (Cash)** کریں۔
4. **شفٹ بند کرنا:** دراز کی نقد رقم گن کر **Close Shift** کریں۔

## عملی مشقیں
1. `Rs. 5,000` سے شفٹ کھولیں، ایک کیش سیل (`Rs. 450`) اور ایک اسپلٹ سیل (`Rs. 1,000` کیش + `Rs. 500` JazzCash) مکمل کریں، پھر شفٹ بند کر کے متوقع کیش (`Rs. 6,450`) چیک کریں۔
2. `F8` سے ایک بل ہولڈ کریں، دوسرا بل بنائیں، اور پھر ہولڈ بل مکمل کریں۔
