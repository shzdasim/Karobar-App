# سیل انوائسز (ریٹیل اور ہول سیل) — صارف مینوئل (اردو)

> **کون استعمال کرتا ہے؟** کیشیئرز، سیلز مین، ہول سیل بلنگ اسٹاف، اسٹور مینیجرز اور فارمیسی مالکان۔  
> **کہاں ملے گا؟** سائیڈ بار → **Invoices → Sale Invoices** (`/sale-invoices`) یا **Wholesale Invoices** (`/wholesale-invoices`)۔ *(تیز بارکوڈ بلنگ کے لیے [بارکوڈ POS](./barcode-pos.md) دیکھیں۔)*

---

## A. مقصد اور تعارف

**سیل انوائسز (Sale Invoices)** ماڈیول میں آپ تفصیلی **ریٹیل** اور **ہول سیل** گاہکوں کے بل بناتے، پرنٹ کرتے، واٹس ایپ/ای میل پر شیئر کرتے اور منظم کرتے ہیں۔

- **میں یہاں کیا کر سکتا ہوں؟** ریٹیل بل (پتہ/یونٹ کی سطح پر) یا ہول سیل B2B بل (ڈبہ/پیک، کسٹمر کے خاص ریٹس اور مفت بونس کے ساتھ) بنائیں، ڈرافٹ محفوظ کریں، A4 یا تھرمل رسید پرنٹ کریں، یا غلط بل کو ریورس (Void) کریں۔
- **یہ روزمرہ کاروبار میں کیسے مدد کرتا ہے؟** ہر پوسٹ شدہ بل خودکار طور پر **FEFO** اصول سے بیچ اسٹاک کم کرتا ہے، منافع کا حساب لگاتا ہے، اور **کیش ڈراور** یا **کسٹمر کھاتہ** اپڈیٹ کرتا ہے۔

---

## B. صارف کیا کر سکتا ہے

- پوسٹڈ نمبر (مثلاً `SI-000001`)، کسٹمر کے نام، اور تاریخ سے بل **تلاش اور فلٹر** کرنا۔
- **ریٹیل سیل انوائس** (`/sale-invoices/create/retail`) بنانا جس میں آئٹم/انوائس ڈسکاؤنٹ، ٹیکس، نقد/بینک/اُدھار ادائیگی اور خودکار ٹریڈ اسکیم بونس شامل ہوں۔
- **ہول سیل انوائس** (`/wholesale-invoices/create` — جب **Sale System Settings** میں فعال ہو) بنانا جس میں Pack Qty، Pack Bonus اور کسٹمر کے خاص ہول سیل ریٹس شامل ہوں۔
- **ہولڈ ڈرافٹس (`Ctrl+H` / `Ctrl+D`)** سے نامکمل بل دوبارہ کھولنا یا حذف کرنا۔
- تھرمل/A4 **پرنٹ** کرنا، واٹس ایپ/ای میل پر PDF **شیئر** کرنا، یا وجہ لکھ کر انوائس **Void / Reverse** کرنا۔

---

## C. اسکرین بہ اسکرین وضاحت

### 1. سیل انوائسز کی فہرست (`/sale-invoices`)

![سیل انوائس انڈیکس](../../../Screenshots/Sale-Invoice-Index.webp)

1. **اوپری ایکشن بار:** **New Retail Sale**، **New Wholesale Sale** (جب فعال ہو)، اور **Held Drafts (`Ctrl+H` / `Ctrl+D`)**۔
2. **سرچ پٹی:** پوسٹڈ نمبر (`SI-000001`) سے تلاش، کسٹمر سے تلاش، اور فی صفحہ تعداد (**Show**)۔
3. **انوائسز ٹیبل:** انوائس نمبر، تاریخ، کسٹمر، قسم (Retail/Wholesale)، ادائیگی کی حالت (Paid / Partial / Unpaid / Voided)، کل رقم، اور ایکشن بٹن (**View**, **Print**, **Share**, **Edit**, **Void / Reverse**)۔

### 2. سیل انوائس بنانا / ایڈٹ کرنا (`/sale-invoices/create/retail`)

![نئی سیل انوائس](../../../Screenshots/Add-Sale-Invoice-page.webp)

1. **انوائس ہیڈر:** انوائس نمبر، تاریخ، **Invoice Type** (*Cash* یا *Credit*)، **Customer** (واک اِن یا نامزد گاہک بمعہ کریڈٹ خلاصہ)، اور **Doctor** (اختیاری)۔
2. **آئٹمز گرڈ:** پروڈکٹ سرچ، **Batch #** (FEFO سے خودکار منتخب)، ایکسپائری، **دستیاب مقدار**، **مقدار**، **بونس**، **قیمت**، **ڈسکاؤنٹ % / رقم**، **ٹیکس**، اور **Sub Total**۔
3. **خلاصہ اور ادائیگی:** مجموعی رقم، انوائس ڈسکاؤنٹ، ٹیکس، **Grand Total**، **Payment Account**، **وصول شدہ رقم**، اور **Save / Save & Print** بٹن۔

### 3. سیل سسٹم موڈ (`Retail` بمقابلہ `Retail + Wholesale`)

![سیل سسٹم سیٹنگز](../../../Screenshots/Sale-System.webp)

- **Settings → Sale System** (`/settings`) سے **Wholesale** فعال کرنے پر ہول سیل انوائسز کا مینو اور پیک لیول بلنگ فارم کھل جاتا ہے۔

## D. ہر فیلڈ، بٹن، ٹیب اور آپشن کی تفصیل

| عنصر | قسم | کیا درج کرنا ہے / کلک کرنے پر کیا ہوتا ہے |
| :--- | :--- | :--- |
| **Customer** | سرچ ڈراپ ڈاؤن | نقد بل کے لیے *Walk-in Customer* رکھیں، یا اُدھار اور خاص ہول سیل ریٹس کے لیے نامزد گاہک چنیں۔ |
| **Invoice Type** | انتخاب | **Cash** (پوری ادائیگی) یا **Credit** (بقایا رقم کسٹمر کھاتہ میں جاتی ہے)۔ |
| **Batch #** | ڈراپ ڈاؤن | سب سے پہلے ایکسپائر ہونے والا بیچ (**FEFO**) خودکار چنتا ہے۔ ایکسپائرڈ بیچ سپروائزر PIN کے بغیر بلاک ہے۔ |
| **Quantity & Bonus** | نمبرز | فروخت کی مقدار درج کریں۔ فعال **Trade Schemes** خودکار **Bonus** یونٹس بھر دیتی ہیں۔ |
| **Discount (%) / Amount** | نمبرز | آئٹم یا پورے بل پر ڈسکاؤنٹ۔ مقررہ حد سے زیادہ ڈسکاؤنٹ پر **Discount Override** (سپروائزر PIN) مانگا جاتا ہے۔ |
| **Tax Rate** | ڈراپ ڈاؤن / % | مقررہ سیلز ٹیکس چنیں یا `0%` رہنے دیں۔ |
| **Total Receive & Account** | ان پٹ / ڈراپ ڈاؤن | آج وصول شدہ رقم لکھیں اور Cash، Bank یا Mobile Wallet منتخب کریں۔ |
| **Held Drafts (`Ctrl+H`)** | ماڈل بٹن | محفوظ شدہ ڈرافٹس دکھاتا ہے تاکہ آپ انہیں **Resume** یا **Discard** کر سکیں۔ |
| **Print / Share** | قطار بٹن | تھرمل/A4 پرنٹ کھولتا ہے یا واٹس ایپ PDF / ای میل شیئرنگ ماڈل کھولتا ہے۔ |
| **Void / Reverse** | قطار بٹن | پوسٹ شدہ بل کو وجہ درج کر کے منسوخ کرتا ہے؛ اسٹاک اور کھاتہ واپس درست ہو جاتے ہیں۔ |

## E. مرحلہ وار استعمال کا طریقہ

### مستقل گاہک کے لیے کریڈٹ (اُدھار) انوائس بنانا
1. **Sale Invoices → Create Retail Sale** (`/sale-invoices/create/retail`) کھولیں۔
2. **Customer** منتخب کریں (مثلاً *Al-Shifa Clinic*) اور **Invoice Type** کو **Credit** پر سیٹ کریں۔
3. دوائیاں شامل کریں (مثلاً *Augmentin 625mg*، مقدار `10` پیک) اور بیچ و ایکسپائری چیک کریں۔
4. اگر گاہک جزوی رقم دے رہا ہے (مثلاً `Rs. 5,500` میں سے `Rs. 2,000`) تو **Total Receive** میں `2000` لکھیں اور **Cash** یا **Bank** منتخب کریں۔
5. **Save & Print** پر کلک کریں۔

### غلط انوائس کو Void (ریورس) کرنا
1. **Sale Invoices** (`/sale-invoices`) میں متعلقہ بل تلاش کریں۔
2. اس قطار پر **Void / Reverse** بٹن دبائیں۔
3. وجہ درج کریں (مثلاً *"غلط کسٹمر منتخب ہو گیا"*) اور تصدیق کریں۔
4. *(نوٹ: اگر اس انوائس پر پہلے ہی Sale Return بن چکا ہو تو Void کرنا ممکن نہیں ہو گا۔)*

## F. عملی کاروباری مثال اور سادہ حساب کتاب

### مثال: ہول سیل بل بمعہ بونس اور جزوی اُدھار
ایک کلینک **Panadol CF** کے **10 پیک** (`Rs. 300/پیک`) خریدتا ہے جس پر **10 + 1 مفت** ٹریڈ اسکیم اور **5% ڈسکاؤنٹ** ہے:
- **کل رقم (Gross Total)** = `10 × Rs. 300 = Rs. 3,000` *(`1` بونس پیک کا بل Rs. 0 ہے)*
- **ڈسکاؤنٹ (5%)** = `Rs. 3,000 × 0.05 = Rs. 150`
- **خالص بل (Net Total)** = `Rs. 3,000 - Rs. 150 = Rs. 2,850`
- **آج وصول شدہ رقم** = `Rs. 1,000` کیش
- **باقی اُدھار** = `Rs. 2,850 - Rs. 1,000 = Rs. 1,850` (کسٹمر کھاتہ میں درج)
- **اسٹاک میں کمی** = `10 + 1 = 11` پیک بیچ سے کم ہوں گے۔

## G. متوقع نتائج

- فروخت اور بونس کی کل مقدار منتخب بیچز سے فوری کم ہو جاتی ہے۔
- وصول شدہ رقم فعال **Cash Drawer** یا بینک/والٹ اکاؤنٹ میں، اور بقایا رقم **Customer Ledger** میں درج ہو جاتی ہے۔

---

## H. عام غلطیاں اور ان کا حل

| غلطی | وجہ | حل |
| :--- | :--- | :--- |
| **کریڈٹ حد کی وجہ سے بل محفوظ نہیں ہو رہا** | گاہک کا اُدھار مقررہ حد سے بڑھ گیا ہے یا اکاؤنٹ ہولڈ پر ہے۔ | جزوی ادائیگی وصول کریں، یا مینیجر سے **Credit Override** کروائیں۔ |
| **سیل انوائس Void/Delete نہیں ہو رہی** | اس بل کے خلاف پہلے ہی **Sale Return** بن چکا ہے۔ | پہلے متعلقہ سیل ریٹرن کو ہٹائیں یا آڈٹ ریکارڈ برقرار رکھیں۔ |
| **Wholesale Invoices مینو نظر نہیں آ رہا** | سیٹنگز میں **Wholesale** موڈ بند ہے۔ | **Settings → Sale System** میں جا کر Wholesale فعال کریں۔ |
