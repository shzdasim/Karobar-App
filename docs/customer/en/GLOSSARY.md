# Pharmacy & Karobar-App Glossary (English)

| Term | Plain-Language Meaning |
| :--- | :--- |
| **Batch / Lot Number** | Manufacturer code printed on a medicine box identifying its production batch and expiry date. |
| **Bonus / Free Qty** | Extra free packs/units given by a distributor on a Purchase Invoice (e.g., 10 + 1 free). |
| **Cash Drawer Shift** | A cashier's daily duty session from **Open Shift** (starting float) to **Close Shift** (physical cash count). |
| **Cost of Sale (COGS)** | What the sold medicines originally cost your pharmacy to buy. |
| **FEFO (First-Expired, First-Out)** | Automatic rule that sells the batch with the earliest expiry date first to prevent expiry loss. |
| **Formulation (Salt / Generic)** | Active chemical ingredient of a medicine (e.g., *Paracetamol*, *Amoxicillin*), used to find substitute brands. |
| **GRN (Goods Receipt Note)** | Entering a distributor's Purchase Invoice into Karobar-App to add stock to shelves. |
| **Hold / Draft Bill** | Temporarily saving an unfinished POS bill so you can serve the next customer in line. |
| **Khata / Ledger** | Running account statement showing all bills, returns, and payments for a Customer or Supplier. |
| **MRP (Maximum Retail Price)** | Official printed retail price on a medicine pack. |
| **Narcotics / Controlled Drugs** | Regulated medicines requiring prescription/register tracking (`/reports/narcotics`) and witness details on disposal. |
| **Operator PIN** | A 4-digit supervisor code used to approve sensitive POS actions (extra discount or expired override). |
| **Pack Size** | Number of sellable units inside one box/pack (e.g., `10` strips or `100` tablets). |
| **Quarantine** | Isolating expired or damaged batches in `/stock-disposals` so cashiers cannot sell them. |
| **Shortbook (User Demands)** | List of medicines requested by patients that are currently out of stock (`/user-demands`). |
| **Stocktake** | Physical counting of shelves (`/stocktake-sessions`) to match computer stock against real stock. |
| **Trade Scheme** | Quantity-based bonus or discount rule offered on bulk purchases or wholesale sales. |
| **Void / Reverse** | Canceling a posted invoice safely so stock and ledger balances return to their previous state. |
