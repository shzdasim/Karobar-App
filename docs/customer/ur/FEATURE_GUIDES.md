# فیچر گائیڈز — اسکرینز اور اختیارات کا حوالہ (اردو)

کاروبار ایپ میں صارف کو نظر آنے والی ہر اسکرین اور اس کے کام کا سادہ تعارف۔ تکنیکی تفصیلات اور فارمولوں کے لیے [MODULE_INVENTORY.md](../../MODULE_INVENTORY.md) دیکھیں۔

## 1. آئٹمز اور ماسٹرز (Items & Masters)

| اسکرین | روٹ (Route) | آپ کیا کر سکتے ہیں |
| :--- | :--- | :--- |
| **پروڈکٹس (Products)** | `/products` | نام، سالٹ، بارکوڈ، برانڈ یا ریک سے تلاش کریں؛ نئی دوائی شامل/ایڈٹ کریں؛ بلک ایڈٹ/ڈیلیٹ اور CSV امپورٹ/ایکسپورٹ کریں۔ |
| **پروڈکٹ بیچز** | `/product-batches` | کسی بھی پروڈکٹ کے تمام بیچز دیکھیں، MRP/ایکسپائری ایڈٹ کریں، یا کاؤنٹر اور گودام کے درمیان اسٹاک منتقل کریں۔ |
| **کیٹیگریز اور برانڈز** | `/categories`, `/brands` | دوائیاں (*Tablets*, *Syrups*) اور کمپنیاں (*GSK*, *Getz*, *Sami*) منظم کریں؛ CSV امپورٹ/ایکسپورٹ کریں۔ |
| **سپلائرز اور کسٹمرز** | `/suppliers`, `/customers` | ڈسٹری بیوٹرز اور اُدھار گاہکوں کا ریکارڈ، اوپننگ بیلنس، ہول سیل ریٹس اور ری فل ریمائنڈرز سیٹ کریں۔ |
| **ڈاکٹرز** | `/doctors` | سیل انوائس پر نسخے کے ریکارڈ کے لیے ڈاکٹروں کے نام محفوظ کریں۔ |
| **بارکوڈ اسٹوڈیو** *(لائسنس: `barcode`)* | `/barcode-labels` | پروڈکٹس، بیچز یا پرچیز آرڈر کے لیے تھرمل/اسٹیکر بارکوڈ لیبلز ڈیزائن اور پرنٹ کریں۔ |

## 2. انوائسز اور آرڈرز (Invoices & Orders)

| اسکرین | روٹ (Route) | آپ کیا کر سکتے ہیں |
| :--- | :--- | :--- |
| **بارکوڈ POS** *(لائسنس: `barcode`)* | `/sale-invoices/pos` | تیز رفتار فل اسکرین بلنگ، بارکوڈ اسکیننگ، FEFO بیچ انتخاب، بل ہولڈ/ڈرافٹ، اسپلٹ ادائیگی اور فوری تھرمل پرنٹ۔ |
| **سیل انوائسز** | `/sale-invoices` | ریٹیل (`/sale-invoices/create/retail`) یا ہول سیل (`/sale-invoices/create/wholesale`) بل بنائیں، ایڈٹ/ریورس کریں، A4/تھرمل پرنٹ کریں اور ای میل/واٹس ایپ پر شیئر کریں۔ |
| **ٹریڈ اسکیمز** | `/trade-schemes` | مقدار کی بنیاد پر بونس/مفت یونٹس اور پروموشنل ڈسکاؤنٹ سیٹ کریں۔ |
| **پرچیز انوائسز** | `/purchase-invoices` | ڈسٹری بیوٹر کے بل (GRN) درج کریں، بیچ بنائیں/اپڈیٹ کریں، بونس شامل کریں اور سپلائر کھاتہ اپڈیٹ کریں۔ |
| **پرچیز آرڈرز اور فورکاسٹ** | `/purchase-orders`, `/purchase-orders/forecast` | فروخت کی رفتار سے اسمارٹ ری آرڈر لسٹ بنائیں، سپلائر کو PO بھیجیں اور وصولی کو پرچیز انوائس میں بدلیں۔ |

## 3. ریٹرنز اور انوینٹری کنٹرولز

| اسکرین | روٹ (Route) | آپ کیا کر سکتے ہیں |
| :--- | :--- | :--- |
| **سیل اور پرچیز ریٹرنز** | `/sale-returns`, `/purchase-returns` | اصل بل کے مطابق مال واپس لیں یا سپلائر کو واپس کریں (سسٹم زائد واپسی سے روکتا ہے) اور کیش یا کھاتے میں سیٹل کریں۔ |
| **بیچ اور ایکسپائری** | `/batch-expiry` | ایکسپائرڈ، قریبی ایکسپائری (30/60/90 دن) اور محفوظ بیچز الگ الگ دیکھیں۔ |
| **یوزر ڈیمانڈز (شارٹ بُک)** | `/user-demands` | گاہکوں کی مانگی گئی عدم دستیاب دوائیاں نوٹ کریں اور انہیں PO میں بدلیں۔ |
| **اسٹاک ایڈجسٹمنٹس** | `/stock-adjustments` | تصدیق شدہ اسٹاک کمی یا زیادتی وجہ کے ساتھ درج کریں۔ |
| **اسٹاک ٹیک سیشنز** | `/stocktake-sessions` | مکمل یا بلائنڈ فزیکل گنتی کریں اور منظور شدہ فرق پوسٹ کریں۔ |
| **قرنطینہ اور ڈسپوزل** | `/stock-disposals` | ایکسپائرڈ/خراب مال کو POS سے الگ کریں، ڈسپوزل سرٹیفکیٹ پرنٹ کریں (نارکوٹکس کے لیے گواہ لازمی)، یا غلطی سے قرنطینہ مال بحال کریں۔ |

| **رپورٹس** | `/reports/*` | نیٹ پرافٹ (P&L)، کاسٹ آف سیل، سیل/پرچیز تفصیل، موجودہ اسٹاک، ری آرڈر، قریبی ایکسپائری، اسٹاک ایڈجسٹمنٹ، ایجنگ، نارکوٹکس رجسٹر، اور ٹیکس ریٹرن *(لائسنس: `fbr`)*۔ |

## 5. سسٹم، شیئرنگ اور ملٹی پی سی

- **سیٹنگز (`/settings`):** دکان کی تفصیل، پرنٹر سیٹ اپ (80mm/58mm/A4)، آپریٹر PIN، فارمیسی کلینیکل اصول، تھیم، SMTP ای میل، واٹس ایپ سائیڈ کار، FBR*، Cube AI*، اور بیک اپ سیٹنگز۔
- **یوزرز اور رولز (`/users`, `/roles`):** اسٹاف اکاؤنٹس اور ان کے اختیارات کنٹرول کریں۔
- **بیک اپس (`/backups`):** SQLite بیک اپ بنائیں، ڈاؤن لوڈ/اپ لوڈ کریں، شیڈول کریں اور ریسٹور کریں۔
- **ملٹی پی سی LAN (`/server-dashboard`):** دکان کے لوکل نیٹ ورک پر جڑے ہوئے تمام کاؤنٹر ٹرمینلز دیکھیں۔
