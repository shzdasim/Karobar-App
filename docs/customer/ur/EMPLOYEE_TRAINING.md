# فارمیسی اسٹاف ٹریننگ نصاب (اردو)

نئے میڈیکل اسٹور کیشیئرز، ڈسپنسرز، اسٹور کیپرز اور شفٹ مینیجرز کے لیے تین سطحوں پر مشتمل عملی تربیتی پروگرام۔

---

## لیول 1 — ابتدائی (کاؤنٹر کیشیئر اور ڈسپنسر)
**ہدف:** واک اِن گاہکوں کو ڈیل کرنا، دوائیاں اسکین کرنا، رسید پرنٹ کرنا، اور کیش ڈراور شفٹ محفوظ طریقے سے چلانا۔

| سبق | سیکھنے کی مہارت | عملی مشق |
| :--- | :--- | :--- |
| **1.1 لاگ اِن اور شفٹ کھولنا** | اپنے ذاتی لاگ اِن سے داخل ہوں؛ صبح کی رقم (`Rs. 5,000`) کے ساتھ `/cash-drawer` میں شفٹ کھولیں۔ | شفٹ کھولیں اور ٹاپ بار پر اپنا نام اور کیش ڈراور اسٹیٹس چیک کریں۔ |
| **1.2 بارکوڈ POS اور سرچ** | `/sale-invoices/pos` کھولیں۔ *Augmentin 625mg* کو نام، سالٹ یا بارکوڈ سے تلاش کریں۔ | `1` پتا (`6` گولیاں) بمقابلہ `1` مکمل ڈبہ (`10` پتے) بیچیں اور یونٹ کنورژن دیکھیں۔ |
| **1.3 بل ہولڈ / ڈرافٹ کرنا** | اگر گاہک پیسے لینے جائے تو نامکمل بل کو `Hold / Draft` پر رکھیں۔ | بل #1 ہولڈ کریں، گاہک #2 کو فارغ کریں، پھر بل #1 واپس کھول کر مکمل کریں۔ |
| **1.4 شارٹ بُک (User Demands)** | جو دوائی اسٹاک میں نہ ہو اسے `/user-demands/create` میں درج کریں۔ | گاہک کے فون نمبر کے ساتھ *Insulatard Penfill* کی ڈیمانڈ درج کریں۔ |
| **1.5 شفٹ بند کرنا** | نقد رقم گنیں اور `/cash-drawer` میں شفٹ بند کریں۔ | گنی ہوئی رقم کو متوقع کیش سے ملائیں (`0` فرق)۔ |

## لیول 2 — درمیانی (انوینٹری، خریداری اور واپسی)
**ہدف:** ڈسٹری بیوٹر سے مال درست طریقے سے وصول کرنا، بیچ/ایکسپائری سنبھالنا، اور سیل/پرچیز ریٹرن پروسیس کرنا۔

| سبق | سیکھنے کی مہارت | عملی مشق |
| :--- | :--- | :--- |
| **2.1 پرچیز انوائس (GRN)** | `/purchase-invoices/create` میں ڈسٹری بیوٹر بل بمعہ **بیچ نمبر**، **ایکسپائری**، **بونس/مفت مقدار**، اور **ٹریڈ ڈسکاؤنٹ %** درج کریں۔ | *GSK ڈسٹری بیوٹر* کا بل درج کریں: `10` پیک + `1` مفت بونس پیک *Panadol CF*، بیچ `B-902`، ایکسپائری `2028-06-30`۔ |
| **2.2 سیل ریٹرن** | اصل سیل انوائس کے مقابلے میں `/sale-returns/create` سے واپس آئی دوائیاں درج کریں۔ | `5` پتوں کی سیل میں سے `2` پتے واپس لیں اور کیش ریفنڈ یا کریڈٹ منتخب کریں۔ |
| **2.3 پرچیز ریٹرن** | قریبی ایکسپائری یا خراب مال `/purchase-returns/create` کے ذریعے ڈسٹری بیوٹر کو واپس کریں۔ | *Muller & Phipps* کو `3` پیک واپس کریں اور سپلائر کھاتہ چیک کریں۔ |
| **2.4 بیچ اور ایکسپائری مانیٹرنگ** | ہفتہ وار `/batch-expiry` اور `/reports/near-expiry-product` چیک کریں۔ | اگلے `60` دن میں ایکسپائر ہونے والے تمام بیچز کی فہرست نکالیں۔ |
| **2.5 بارکوڈ لیبل اسٹوڈیو** | بغیر بارکوڈ والی آئٹمز کے لیے `/barcode-labels` سے اسٹیکر پرنٹ کریں۔ | پروڈکٹ نام، MRP اور بیچ نمبر والا بارکوڈ لیبل بنائیں۔ |

## لیول 3 — ایڈوانس (مینیجر، فنانس اور کنٹرولز)
**ہدف:** اُدھار کھاتے، فزیکل اسٹاک ٹیک، قرنطینہ ڈسپوزل، اخراجات اور منافع/نارکوٹکس رپورٹس کو کنٹرول کرنا۔

| سبق | سیکھنے کی مہارت | عملی مشق |
| :--- | :--- | :--- |
| **3.1 کریڈٹ اور پیمنٹ واؤچرز** | `/payments` میں گاہکوں سے وصولی اور ڈسٹری بیوٹر ادائیگی درج کریں اور کھاتے چیک کریں۔ | دو زیرِ التواء بلوں کے مد میں `Rs. 15,000` وصول کریں اور رسید پرنٹ/واٹس ایپ کریں۔ |
| **3.2 اسٹاک ٹیک اور ایڈجسٹمنٹس** | `/stocktake-sessions` میں بلائنڈ/گائیڈڈ گنتی چلائیں اور `/stock-adjustments` سے درستگی کریں۔ | *Antibiotics* ریک کی گنتی کر کے فرق فائنلائز کریں۔ |
| **3.3 قرنطینہ اور ڈسپوزل** | ایکسپائرڈ/خراب مال `/stock-disposals/create` میں قرنطینہ کریں؛ نارکوٹکس کے لیے گواہ درج کریں۔ | ایک ایکسپائرڈ بیچ کو قرنطینہ کریں تاکہ POS پر فروخت نہ ہو سکے۔ |
| **3.4 رپورٹس اور کمپلائنس** | `/reports/net-profit`، `/reports/cost-of-sale`، `/reports/current-stock`، اور `/reports/narcotics` کا جائزہ لیں۔ | ماہانہ Net Profit (P&L) PDF ایکسپورٹ کریں اور اخراجات کی کٹوتی چیک کریں۔ |
| **3.5 آپریٹر PIN اور اوور رائیڈز** | ایڈمن پاس ورڈ دیے بغیر سپروائزر PIN کے ذریعے جائز ڈسکاؤنٹ یا ایکسپائری اوور رائیڈ کی اجازت دیں۔ | POS پر `5%` ڈسکاؤنٹ اپنے 4 ہندسوں کے PIN سے منظور کریں۔ |
