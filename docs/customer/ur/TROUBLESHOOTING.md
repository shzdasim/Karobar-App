# کسٹمر ٹربل شوٹنگ اور غلطیوں کی اصلاح (اردو)

فارمیسی اسٹاف کو پیش آنے والے عام مسائل اور اسٹاک یا کھاتوں کو خراب کیے بغیر ان کا محفوظ حل۔

---

| مسئلہ / ایرر | ممکنہ وجہ | محفوظ حل کا طریقہ |
| :--- | :--- | :--- |
| **شیلف پر دوائی موجود ہے لیکن POS پر "Insufficient stock" آ رہا ہے** | پرچیز انوائس درج نہیں ہوئی یا کسی دوسرے بیچ میں درج ہے۔ | 1. `/product-batches` میں دوائی چیک کریں۔<br>2. اگر ڈسٹری بیوٹر کا بل درج نہیں ہوا تو **Purchase Invoice** بنائیں۔<br>3. تصدیق کے بعد بھی فرق ہو تو **Stock Adjustment** (`/stock-adjustments/create`) استعمال کریں۔ |
| **POS پر "Batch is expired" کا الرٹ** | بیچ کی ایکسپائری تاریخ گزر چکی ہے۔ | ایکسپائرڈ دوائی **ہرگز** فروخت نہ کریں۔ اسے فوراً **قرنطینہ (`/stock-disposals/create`)** میں ڈالیں اور نیا بیچ منتخب کریں۔ |
| **شفٹ کلوزنگ پر کیش ڈراور میں رقم کم یا زیادہ ہے** | کوئی نقد خرچہ درج کرنا بھول گئے یا کیش سیل کو غلطی سے کریڈٹ/بینک مارک کر دیا۔ | 1. `/cash-drawer` میں شفٹ کی تمام ٹرانزیکشنز دیکھیں۔<br>2. رہ جانے والا خرچہ `/expenses` میں درج کریں۔<br>3. اگر اسی شفٹ کا بل ہے تو ادائیگی کا طریقہ درست کریں۔ |
| **پرچیز انوائس ڈیلیٹ نہیں ہو رہی** | اس خریداری کے بیچ میں سے کچھ مال پہلے ہی فروخت ہو چکا ہے۔ | مال بکنے کے بعد پرچیز بل ڈیلیٹ نہیں ہو سکتا۔ باقی مال کے لیے **Purchase Return** (`/purchase-returns/create`) بنائیں۔ |
| **سیل انوائس ڈیلیٹ نہیں ہو رہی** | اس انوائس کے خلاف **Sale Return** بن چکا ہے۔ | پہلے متعلقہ سیل ریٹرن کو ہٹائیں، یا آڈٹ ریکارڈ کے لیے انوائس کو برقرار رکھیں۔ |
| **تھرمل رسید پرنٹ نہیں ہو رہی یا کٹی ہوئی آ رہی ہے** | غلط پرنٹر یا غلط پیپر سائز (58mm بمقابلہ 80mm) منتخب ہے۔ | **Settings → Printer Settings** (`/settings`) کھولیں، درست Windows پرنٹر اور `80mm`/`58mm` چن کر **Test Print** کریں۔ |
| **واٹس ایپ پر PDF نہیں جا رہی** | لوکل واٹس ایپ سیشن لاگ آؤٹ ہو گیا ہے یا نمبر میں کنٹری کوڈ (`92`) نہیں ہے۔ | **Settings → WhatsApp** میں QR کوڈ دوبارہ اسکین کریں اور گاہک کا نمبر `92` سے شروع کریں (مثلاً `923001234567`)۔ |
| **LAN ٹرمینل پر "Server Offline" آ رہا ہے** | مین سرور کمپیوٹر بند ہے، IP تبدیل ہو گیا ہے، یا فائر وال نے پورٹ بلاک کی ہے۔ | یقینی بنائیں کہ سرور کمپیوٹر پر کاروبار ایپ چل رہا ہے، سرور پر `/server-dashboard` چیک کریں اور Network Settings میں **Troubleshoot** چلائیں۔ |
