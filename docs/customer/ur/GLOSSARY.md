# فارمیسی اور کاروبار ایپ لغت / اصطلاحات (اردو)

| اصطلاح (Term) | آسان اردو وضاحت |
| :--- | :--- |
| **Batch / Lot Number (بیچ نمبر)** | دوائی کے ڈبے پر چھپا ہوا کمپنی کا کوڈ جو اس کی تیاری اور ایکسپائری تاریخ کی نشاندہی کرتا ہے۔ |
| **Bonus / Free Qty (بونس مقدار)** | ڈسٹری بیوٹر کی طرف سے خریداری پر ملنے والے مفت ڈبے یا پتے (مثلاً 10 کے ساتھ 1 مفت)۔ |
| **Cash Drawer Shift (کیش ڈراور شفٹ)** | کیشیئر کی ڈیوٹی کا دورانیہ: **Open Shift** (صبح کی رقم) سے **Close Shift** (رات کی گنتی) تک۔ |
| **Cost of Sale / COGS (لاگتِ فروخت)** | فروخت کی گئی دوائیوں کی اصل قیمتِ خرید۔ |
| **FEFO** | پہلے ایکسپائر ہونے والا بیچ پہلے فروخت کرنے کا خودکار اصول تاکہ مال ضائع نہ ہو۔ |
| **Formulation / Salt (سالٹ / فارمولا)** | دوائی کا اصل کیمیائی جزو (مثلاً *Paracetamol*) جس سے متبادل برانڈ تلاش کیے جاتے ہیں۔ |
| **GRN / Purchase Invoice** | ڈسٹری بیوٹر سے آنے والے مال کا بل سسٹم میں درج کرنا تاکہ اسٹاک بڑھ جائے۔ |
| **Hold / Draft Bill (ہولڈ بل)** | نامکمل بل کو عارضی طور پر محفوظ کرنا تاکہ لائن میں کھڑے اگلے گاہک کو فارغ کیا جا سکے۔ |
| **Khata / Ledger (کھاتہ)** | گاہک یا سپلائر کے تمام بلوں، واپسیوں اور ادائیگیوں کا مکمل چلتا ہوا حساب۔ |
| **MRP** | دوائی کے پیک پر درج زیادہ سے زیادہ سرکاری قیمتِ فروخت۔ |
| **Narcotics / Controlled Drugs** | وہ حساس ادویات جن کی فروخت کا الگ رجسٹر (`/reports/narcotics`) اور ضائع کرتے وقت گواہ ضروری ہوتا ہے۔ |
| **Operator PIN (آپریٹر پن)** | سپروائزر کا 4 ہندسوں کا خفیہ کوڈ جو POS پر اضافی ڈسکاؤنٹ یا اوور رائیڈ کی اجازت دیتا ہے۔ |
| **Pack Size (پیک سائز)** | ایک ڈبے میں موجود یونٹس/پتوں کی تعداد (مثلاً `10` پتے یا `100` گولیاں)۔ |
| **Quarantine (قرنطینہ)** | خراب یا ایکسپائرڈ مال کو `/stock-disposals` میں الگ کرنا تاکہ کاؤنٹر پر فروخت نہ ہو سکے۔ |
| **Shortbook / User Demands** | ان دوائیوں کی فہرست جو گاہکوں نے مانگیں لیکن دکان میں موجود نہیں تھیں (`/user-demands`)۔ |
| **Stocktake (اسٹاک ٹیک)** | شیلف پر موجود اصل مال کو گن کر کمپیوٹر کے ریکارڈ سے ملانا (`/stocktake-sessions`)۔ |
| **Trade Scheme (ٹریڈ اسکیم)** | زیادہ مقدار کی خریداری یا ہول سیل پر ملنے والے بونس یا ڈسکاؤنٹ کے اصول۔ |
| **Void / Reverse (ریورس کرنا)** | کسی پوسٹ شدہ بل کو محفوظ طریقے سے منسوخ کرنا تاکہ اسٹاک اور کھاتہ واپس درست ہو جائیں۔ |
